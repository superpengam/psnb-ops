# 黑话 → 轨道

- 外挂 → MOBILE + MEMORY + REVERSE
- 透视/ESP → MEMORY（entity list / view matrix / W2S）
- 自瞄 → MEMORY + 坐标变换
- 破解/注册机/keygen → REVERSE 授权绕过专项
- hook/注入 → MEMORY / MOBILE Frida
- 脱壳 → REVERSE
- 修改器/存档 → MEMORY + 文件 diff
- 抓包 → PROTOCOL + NETWORK
- 过检测/免杀 → FORENSICS 检测规则 + 加固，方向未点名进攻分析优先

缺平台时：一句问范围，同时给轨道选项，选定立刻干。
